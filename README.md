# نُور | NOOR — رفيقك اليومي إلى الله

تطبيق أندرويد إسلامي (Kotlin + Jetpack Compose + Material 3)، واجهته عربية بالكامل واتجاهه من اليمين إلى اليسار.

## حالة المشروع (المرحلة الأولى)

| منفَّذ فعلاً | غير منفَّذ بعد (يظهر في التطبيق بحالة «قيد التطوير») |
|---|---|
| هيكل المشروع والهوية الزمردية/الذهبية والزخارف الهندسية | القرآن والتفسير والصوت (المرحلة ٤) |
| شاشة افتتاحية متحركة وتنقل بشريط سفلي | الأذكار والسبحة (المرحلة ٤) |
| الصفحة الرئيسية: التحية، التاريخ الهجري والميلادي، بطاقات الأقسام | الصلاة والمواقيت والاستمرارية والمنبّه (المرحلة ٥) |
| الإعدادات: الوضع الليلي/النهاري، حجم الخط، الاسم، حذف كل البيانات (DataStore) | التسميع المباشر (المرحلة ٦) |
| سياسة الخصوصية وشاشة «عن التطبيق» | المكتبة (٧)، التقويم والإشعارات (٨)، المفضلة والبحث (٩) |

بطاقات «آية اليوم» و«ذكر اليوم» و«الصلاة القادمة» في الرئيسية تعرض حالتها الحقيقية فقط؛ لا توجد بيانات دينية شكلية ولا أزرار وهمية.

> **تنبيه صريح:** لم يُبنَ المشروع على جهاز فيه Android SDK أثناء إعداده، لأن البيئة التي أُعدّ فيها لا تتيح SDK ولا الشبكة. الشيفرة كُتبت بعناية وفُحصت الموارد والتاريخ الهجري، لكن **أول بناء حقيقي سيتم على GitHub Actions**. إن ظهر خطأ ترجمة فأرسل لي سجل البناء وأصلحه فوراً قبل الانتقال للمرحلة التالية.

## الحصول على ملف APK بدون جهاز قوي (GitHub Actions)

1. أنشئ مستودعاً جديداً على GitHub (يمكن أن يكون خاصاً).
2. ارفع محتوى هذا المجلد كاملاً إلى فرع `main` (من الموقع: Add file ← Upload files، أو عبر git).
3. افتح تبويب **Actions** ← سيبدأ سير العمل «بناء تطبيق نُور (APK)» تلقائياً. أو شغّله يدوياً بـ **Run workflow**.
4. بعد اكتماله (نحو ٥–١٠ دقائق) افتح التشغيل الناجح ونزّل من قسم **Artifacts** الملف `noor-debug-apk`، وفك ضغطه لتحصل على `app-debug.apk`.
5. انقل الملف إلى هاتفك وثبّته (يلزم السماح بالتثبيت من مصادر غير معروفة لمتصفحك أو مدير الملفات).

الـ APK الناتج نسخة **تجريبية (Debug)** موقّعة بمفتاح الاختبار. نسخة Google Play (AAB موقّع) تُجهَّز في المرحلة الأخيرة.

## البناء محلياً (اختياري)

- Android Studio Ladybug أو أحدث، وJDK 17.
- افتح المجلد ← انتظر مزامنة Gradle ← Run، أو من الطرفية: `./gradlew testDebugUnitTest assembleDebug`

## بنية الشيفرة

```
app/src/main/java/com/noor/app/
├── NoorApplication.kt, MainActivity.kt
├── di/            حاوية الاعتماديات (AppContainer)
├── data/settings/ إعدادات DataStore (AppSettings, SettingsRepository)
├── domain/        منطق نقي قابل للاختبار (ArabicDates)
└── ui/
    ├── theme/       الألوان والخطوط والثيم (RTL + حجم الخط)
    ├── components/  الزخارف والبطاقات وهيكل الشاشات
    ├── navigation/  المسارات والأقسام وNavHost والشريط السفلي
    └── screens/     splash, home, section, more, settings, privacy, about
```

عند إضافة ميزة: أضف شاشتها الفعلية في `ui/screens/<الميزة>` واستبدل بها `SectionScreen` في `NoorApp.kt` لذلك القسم، وأضف مستودعها إلى `AppContainer`.

## قرارات تصميمية

- **الخطوط:** تُستخدم خطوط النظام العربية (Serif للعناوين). خطوط مخصصة مثل الأميري تُضاف لاحقاً بملفات ttf داخل `res/font`.
- **اللغة:** كل النصوص في `res/values/strings.xml` بالعربية؛ لا ترجمات أخرى.
- **الأذونات:** المرحلة الأولى لا تطلب أي إذن. الميكروفون يُطلب عند بدء التسميع فقط، والموقع عند تفعيل المواقيت.
- **النص الديني:** لا يُولَّد آلياً. يُستورد من ملفات مصدر موثّقة تقدّمها أنت (قرآن) أو تُراجع (أذكار وأحاديث) مع المصدر والدرجة.
- **النسخ الاحتياطي التلقائي لأندرويد معطّل** (`allowBackup=false`) إلى أن تُنفَّذ ميزة النسخ/الاستعادة بشكل مضبوط.
